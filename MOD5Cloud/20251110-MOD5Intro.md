# Cloud Deployments with AWS

Date: *10 Nov 2025*

## Learning Objectives

* Explain how computers communicate, reliably and securely, over a network using shared physical connections
* Explain a technical topic, clearly and concisely, to a small audience
* Learn to manually deploy a simple 'Dockerised' app to AWS
* Learn to automate deployment using a simple script

## Teaching

We want you to walk away with something deeper: an understanding of what the cloud actually is, a sense of how the internet works underneath it all, and the ability to look at a complex AWS dashboard and think "I may not know every button—but I know what matters."

## Basics

So in this module, we'll go back to the roots of the internet: IP addresses, ports, DNS, requests and responses, the raw connections underneath it all. Because when you know the terrain, the tools make sense.

## Phases

1. **Networking:** Before deploying to the cloud, we'll explore the internet's foundation. This phase covers how devices communicate using IP addresses, DNS, and core protocols. Understanding this is key to configuring and troubleshooting cloud services.

2. **Deploying Applications:** Here, we'll take a containerized application and make it live on AWS. This involves the hands-on process of provisioning cloud infrastructure, configuring the environment, and running our application on a server for the world to access.

3. **CI/CD (Continuous Integration/Continuous Deployment):** The final phase is about automation. We will build pipelines that automatically test and deploy our code whenever changes are pushed. This practice minimizes manual errors and enables faster, more reliable software delivery.
